# Physics-Particle-System
A simulation of particles undergoing motion due to laws of physics like gravity, collisions etc. This is a beginner project made by me using Raylib and C++.

#Controls:
1. Hold your left mouse button to start creating a new particle in the position of your cursor.
2. The size and mass of the particle depends on the time held while creating it.
3. Velocity of the particle can be choosen by dragging the particle back like dragging a slingshot.
4. Press Space key to pause the simulation, so that more particles can be added at the same time.
5. Press Space key again to unpause the simulation.
